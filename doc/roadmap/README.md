# Zenoh Roadmap

This directory contains the project roadmap and feature tracking for Zenoh.

## Vision

Zenoh aims to become the standard data distribution middleware for edge computing, IoT, and robotics applications, providing unified access to data in motion, data at rest, and computations.

## Current Focus Areas

### 1. Core Protocol
- Protocol stability and standardization
- Performance optimizations
- Enhanced routing capabilities

### 2. Ecosystem
- Language bindings expansion
- Integration with popular frameworks
- Tool development

### 3. Features
- Advanced time-series support
- Enhanced security features
- Improved monitoring and observability
