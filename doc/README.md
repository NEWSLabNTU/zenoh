# Zenoh Project Documentation

This directory contains internal working documents for the Zenoh project development team. These documents capture architectural decisions, design studies, and implementation details.

## Directory Structure

- **[architecture/](architecture/)** - System architecture documentation
- **[design-decisions/](design-decisions/)** - Architecture Decision Records (ADRs)
- **[studies/](studies/)** - Performance, scalability, and compatibility studies
- **[roadmap/](roadmap/)** - Project roadmap and feature tracking
- **[api-evolution/](api-evolution/)** - API change tracking and evolution
- **[research/](research/)** - Research topics and related papers

3. Follow the established templates for consistency
4. Include diagrams where helpful (use Mermaid or ASCII art)
